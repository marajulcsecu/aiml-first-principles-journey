## Core Engineering & Research Philosophy
1. **Mastery-Gated, Not Calendar-Rushed:** Advance from Stage `N` to Stage `N+1` ONLY after passing concrete Build / Break / Experiment / Feynman Mastery Gates—whether the full journey takes 5, 10, or 20+ years.
2. **Just-in-Time Detailed Planning:** Maintain a timeless high-level dependency map (Stages 0–8), and expand deep module syllabi **only for the active Stage** so fast-moving frontier topics stay fresh when reached.
3. **Zero Black-Box Magic:** Implement core primitives from scratch in pure Python/NumPy/PyTorch before reaching for high-level abstractions; deliberately break models/pipelines to develop true diagnostic intuition.
4. **Socratic AI Only (No Illusion of Competence):** Use AI strictly as a 24/7 professor, intuition builder, and code/experiment reviewer—never to autopilot lab solutions.
5. **Local-CPU-First → Cloud-GPU-Ready:** Master Stages 0–3 cleanly on lightweight local CPU hardware (`i5`, `7.4 GiB` RAM), then scale seamlessly to Cloud GPUs in Stages 4–8.
